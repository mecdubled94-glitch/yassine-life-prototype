# Yassine Life Prototype

Ce prototype est une base jouable pour un jeu en monde ouvert narratif inspiré de ton concept.

Fonctionnalités de la version actuelle :
- personnage jouable
- déplacement de base à pied
- voiture drivable
- entrée/sortie de véhicule avec la touche E
- PNJ qui se déplacent dans la ville
- système d'argent et de police (heat)
- mission simple : trouver la voiture puis aller jusqu'au point de livraison
- interface HUD simplifiée
- cycle jour/nuit très léger

Comment lancer :
1. Ouvrir le projet Godot 4.2+
2. Ouvrir la scène Main.tscn
3. Appuyer sur F5 pour lancer le jeu

Contrôles :
- ZQSD ou flèches : déplacement
- Shift : courir
- E : entrer ou sortir d'une voiture

Limites de ce prototype :
- une seule petite zone
- pas encore de vrais quartiers, factions ni dialogues
- pas encore de ville massive ni de monde avancé
- système de police, missions et économie encore simplifiés

Le but est de poser une base solide, jouable et extensible pour une suite plus grande.
